# 《未完成的星路》

給孩子玩的瀏覽器 2D 像素冒險遊戲。

## 目標

- 視覺：超級任天堂後期至早期 32-bit 主機感
- 流暢度：以 60 FPS 為目標
- 平台：桌面與平板瀏覽器
- 部署：Netlify 靜態網站
- 技術：HTML5 Canvas、CSS、原生 JavaScript
- 外部依賴：無

## 第一個可玩段落

C01「同一座標的兩個入口／五年後第一次共同救人」。玩家切換長子尤哈尼與長女珊妮，結合正式救援與地下道路，救出被困居民並重新建立最低合作。

## 操作

- 方向鍵／WASD：移動
- Z／空白鍵：互動
- X／Shift：切換角色
- Esc：暫停

## 開發分工

- System Director／Integrator：技術架構、版本控制、Netlify、整合
- Narrative & Visual Design：劇情轉譯、場景、美術規格、UI
- Red Team & QA：玩法漏洞、效能、兒童可理解性、邊界條件
- Implementation：Canvas 引擎、角色控制、場景、存檔與部署

所有工作均在本倉庫內完成，不要求使用者另外安裝遊戲引擎、素材包或建置工具。
